# العامر مول — V12

تم الرجوع إلى تصميم V9 الأصلي المبني على React وVite، دون قالب NextMerce.

## التحديثات
- عدادات زيارات متحركة، أرقام العام والشهر وأمس حتى نهاية أمس بتوقيت السعودية.
- خط زمني شهري وآخر 8 أسابيع، رسم مقارنة شهرية مع 2025، وجدول تفصيلي.
- حذف لوحة «وتيرة العام الجديد»، والحفاظ على حركة الرسم والأعمدة ودعم تقليل الحركة.
- معرض موسع إلى 8 صور حقيقية من أصول المشروع، مشغل فيديو محلي، ومشغلات LinkedIn الحالية مع روابط بديلة.
- بطاقة معلومات إضافية تستند إلى منشور قناة المول.

## مصدر الأرقام
الرقم التاريخي الوحيد المقدم من الإدارة: 7,400,000 زيارة في 2025. أرقام 2026 وتوزيع 2025 شهريًا وأسبوعيًا تقديرات موسمية، وليست سجلات فعلية أو إشغالًا لحظيًا. النمو المفترض 6%؛ يضبط في src/components/business/MallStatistics.tsx. الإجمالي السنوي المتوقع 7,844,000؛ العرض التراكمي يستبعد اليوم الحالي.

## التشغيل
```sh
npm ci
npm run dev
```
## بناء الموقع
```sh
npm run build
```
ارفع محتويات dist إلى الاستضافة، مع توجيه مسارات الموقع إلى index.html. ملف dist جاهز داخل الحزمة.

## التحقق
نجح بناء Vite وفحص TypeScript واختبارات حساب الزيارات الثلاثة. تشغيل فيديوهات LinkedIn يعتمد على المنصة ولم يتم التحقق بصريًا منه. تمت إضافة أربعة فيديوهات اجتماعية محلية جديدة في V12 بجانب المشغلات السابقة.

## إضافات V12
- تسويق تجربة المول بصياغة غير مباشرة، وزر البداية إلى تخطيط الزيارة.
- عناوين الزيارات بلا تكرار كلمة التقديرية، مع توضيح ظاهر واحد بأن الأرقام محسوبة وليست قياسات فعلية، ومنهجية مفصلة.
- أربعة فيديوهات محلية أصلية من حساب العامر مول: اليوم الوطني 96، افتتاح بولو كلوب، عيد الأضحى وعيد الفطر، مع صور أغلفتها. مصادر المنشورات في public/media/events/sources.json.
- قسم تفاعلي لاختيار المشاهد، تشغيل صامت عند الظهور، توقف عند الخروج من الشاشة، وتحكم يدوي وصوت. يراعي تقليل الحركة.
- معرض من 12 صورة، صور ست علامات، وصورة حقيقية لمتجر بولو كلوب في دليل المتاجر والأخبار.
- حركة صورة البداية، دخول العنوان، تفاعل البطاقات والأزرار وصور العلامات.
- نجح عرض قسم الإحصاءات والمشاهد بالعربية والإنجليزية، وفحص ملفات الفيديو H.264/AAC عبر ffprobe. لم يتم اختبار تشغيل الفيديو والتفاعل داخل متصفح فعلي.
